# Carte des données

## Statut

Le dataset n'est pas inclus dans le dépôt et n'est pas analysé dans cette
phase. Aucune statistique de volume, de durée, de qualité ou de distribution
n'est donc publiée.

## Schéma attendu

Les configurations prévoient au minimum une référence audio, une transcription
et un identifiant de locuteur. Les langues du MVP sont le français (`fr`) et le
dioula (`dyu`). La provenance, les licences, le consentement, les conditions de
collecte et les risques de biais devront être documentés avant utilisation.

## Partitionnement

Les futurs ensembles d'entraînement, validation et test seront séparés
strictement par locuteur afin d'éviter toute fuite entre partitions. Le baoulé
pourra être ajouté ultérieurement avec sa propre configuration.
