# Development selection finalizer

## Status

Completed — Codex, 2026-08-11. The host finalizer was not executed.

## Objective

Add a guarded, decision-only and idempotent stage that consumes the existing
terminal-validation aggregate report and atomically finalizes the development
checkpoint selection without any evaluation or data access.

## Scope

Included: candidate-report validation, checkpoint and run identity checks,
official ranking and refit-budget recalculation, atomic decision update,
history preservation, aggregate audit report, Make entry point, tests and
protocol documentation.

Excluded: running the finalizer, loading audio or model weights, evaluation,
training, refit, final-holdout access, committing or pushing.

## Acceptance criteria

- consumes only the frozen decision, aggregate candidate report and hashes;
- blocks when refit/final-holdout activity exists or confirmation is absent;
- validates status, config, run, checkpoint, validation and metric identities;
- recalculates selection with `metric_rank` and budget with
  `refit_step_budget` without hardcoded results;
- preserves the provisional 1507/1798 decision in the finalized audit trail;
- updates `development_decision.json` atomically without checkpoint writes;
- identical reruns return `already_finalized_same_decision`; mismatches stop;
- no audio, manifest row, prediction, evaluator or model loader is reachable;
- public output remains aggregate-only and outside Git;
- targeted tests and all repository quality gates pass.

## Decisions

- The development run commit remains historical provenance; a separate
  finalization commit is recorded and becomes the code identity required by
  refit.
- The existing candidate report is never regenerated by the finalizer.
- The refit still starts from pilot `checkpoint-000140`; development selection
  changes only its optimizer-step budget.
